# Changelog — v1.0.11

Changes shipped between v1.0.1 (`17a64eac`) and v1.0.11.

---

## Fixes

- Fixed a bug where users checking out on staged ticket tiers (e.g. Early Bird, General) were hitting the wrong tier in the backend, causing failed purchases.
- Fixed Apple Pay not showing up in the mobile payment sheet — the payment sheet now initialises in the correct platform context.
- Fixed Apple Pay accent color in web checkout appearing red (like an error) instead of neutral white.
- Fixed a sign-in loop on mobile where users were being redirected incorrectly after logging in during checkout.
- Fixed an identity mismatch error that was preventing some users from completing the hold step during checkout.
- Fixed access codes (secret codes on ticket tiers) not being compared correctly when users entered them in uppercase or with spaces — comparison is now consistent everywhere.
- Fixed the RSVP payment modal's loading button sometimes getting stuck after a failed access code attempt.
- Fixed multi-organization support — organizers managing more than one org now land on the correct org's data throughout the dashboard, settings, and event pages.
- Fixed org member roles not being respected correctly in the organizer dashboard.
- Fixed events not loading correctly for organizers who are not the primary owner of an organization.

## Improvements

- Added Apple Pay support to the Stripe checkout flow on mobile.
- Added an access code entry modal on mobile that matches the web experience — users with restricted ticket tiers are prompted to enter their code before completing checkout.
- Stripe Connect onboarding now shows a proper confirmation screen on mobile after completing the payout account setup.
- Ticket tier sales end date now validates against when the event ends rather than when it starts, giving organizers more flexibility.
- Event creation now pre-fills the ticket sales end date using the event end date.
- Event creation validation errors are now shown inline instead of as alert popups.
- Registration form answers are now included in RSVP exports (both web and mobile).
- Notification emails for free tickets and bank transfer tickets now use dedicated, improved templates.
- Email layouts and styles improved across ticket confirmation, date change, and promotional notifications.
- Stripe onboarding error messages are now more descriptive — organizers see clearer guidance when their payout account has issues.
- Event sharing on mobile now sends a clean URL-only message for better cross-platform compatibility.
- Ticket tier cards on mobile now show the current stage name as the main title and the tier name as a subtitle.
- Organizer dashboard updated to support EAS over-the-air updates on iOS.
- Mobile app updated to Clerk v3 for authentication.
- Event poster images standardized to 3:4 aspect ratio across web and mobile.
- Internal admin panel removed (functionality consolidated).
